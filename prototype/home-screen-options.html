Gallery Shelf, plus nine other home screens

The launcher in this repo already ships with zero ads, sponsored rows or network access, so every option below keeps that. What changes is layout and how the remote moves through it. Each frame is drawn at 16:9 to read the way it would from the sofa.

Ship firstOption 1, 3 or 7. They run on config keys that already exist, so a theme folder with a config.json is the whole change, no APK rebuild.
Most interesting for AVOption 5 (meeting room) and 9 (hospitality). Inputs-first is where stock Android TV is weakest, and it needs one off-by-default launcher switch.
Fork territoryOptions 6, 8 and 10 restructure navigation. The repo rules send heavy restyles to your own repository plus a row in SHOWCASE.md.
Theme existing config keys only Switch small launcher change, off by default Fork new layout code, own repo

The background is a blurred copy of the focused card's artwork, fading as focus moves. Hover a card to see it change. On the TV this reuses the launcher's existing HeroArt trick, a 48×27-pixel copy stretched to full screen, so there is no blur pass. Stand-in photos, made-up titles.

Mockups, not TV captures. Wallpaper is the real 13-lighthouse-coast.jpg from the theme's set.

From Apple TV: the top shelf naming the focused app, a glass highlight that lifts the tile, a colour glow on the focused tile only, and the Apple TV app's left sidebar for navigation.

From Gallery Wall: a full-bleed photo that rotates every 30 minutes, its place name top right, no greeting, and the clock screensaver drawn over the same photo.

The sidebar replaces the top-right buttons. Home, App library, Inputs, Clock and Settings already exist in the launcher; the sidebar only moves them to one place on the left. It has no search or account items, because the launcher has no network access.
